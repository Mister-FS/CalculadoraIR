# CalculadoraIR

A simple Python script for calculating Brazilian income tax (Imposto de Renda - IR). This project is designed for educational purposes and demonstrates tax calculation based on user input.

## Features:
- Calculates income tax for individuals based on Brazilian tax rates.
- Supports different income brackets and tax rates.
- Interactive command-line interface for easy use.

## Usage:

1. Once the script is executed, it will prompt you to enter your monthly income.
2. The script will then calculate and display the corresponding income tax based on Brazilian tax brackets.

3. Example:
Enter your monthly income: 5000
Your calculated income tax: R$ X.XX
